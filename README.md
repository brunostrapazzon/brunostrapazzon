### Projeto principal

**[NetDoctor](https://github.com/brunostrapazzon/NetDoctor)**: diagnóstico de internet para Windows. Um clique, uns 10 segundos, e ele diz em português simples o que está acontecendo e o que fazer.

- O diagnóstico sai de regras fixas e testadas. A IA é opcional e só reescreve a explicação; quem decide são as regras.
- Funciona sem internet, que é justamente quando alguém precisa dele.
- A IA nunca recebe nome da rede, IP ou MAC. Isso é garantido por teste, não por promessa.
- 279 testes com saídas reais do Windows em português e inglês. O GitHub Actions testa, gera o `.exe` e publica o release.

[Baixar o NetDoctor.exe](https://github.com/brunostrapazzon/NetDoctor/releases/latest)
